# My Portfolio

This is my personal portfolio website built with:
- React (Vite)
- Node.js & Express
- MongoDB

## Running Locally

1. Install dependencies for both frontend and backend:
   ```bash
   npm install
   cd frontend && npm install
   ```

2. Set up environment variables:
   Create a `.env` file in the `backend/` directory with your database URI and other configurations.

3. Start the application:
   - Backend: `npm run dev` in the root folder.
   - Frontend: `npm run dev` in the `frontend/` folder.
